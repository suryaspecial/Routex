# 🌍 Routex – Travel Website

Routex is a modern and responsive travel website designed to showcase travel destinations, experiences, and travel-related services through a clean and visually engaging interface.

The project focuses on responsive web design, modern layouts, interactive components, and an enjoyable user experience across desktop, tablet, and mobile devices.

## 🌐 Live Demo

👉 [View Routex Live Website](https://suryaspecial.github.io/Routex-travel-website/)

## ✨ Features

- 🌍 Modern travel website design
- 📱 Fully responsive layout
- 🖥️ Desktop, tablet, and mobile support
- 🧭 Responsive navigation bar
- 🏞️ Destination and travel sections
- 🖼️ Image-based destination showcases
- 🎨 Modern and clean UI design
- ✨ Hover effects and interactive elements
- 📜 Smooth scrolling
- 📱 Mobile-friendly interface
- 🔗 Social media and navigation links
